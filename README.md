# Verelyn plugin

Connects a client to the remote service at https://verelyn.com/api/mcp. Sign in through the client's browser flow and approve only what you intend. Never paste tokens or passwords into a chat.

Documentation: https://docs.verelyn.com · Privacy: https://verelyn.com/privacy · Terms: https://verelyn.com/terms

This package holds configuration and brand files only. No platform listing, review or client support is claimed.
